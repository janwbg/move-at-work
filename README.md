# Move at work

Ein minimalistischer React/Vite-MVP für Bewegungsimpulse im Arbeitsalltag.

## Lokal starten

```bash
npm run dev
```

## Build prüfen

```bash
npm run build
```

## Struktur

- `src/components`: UI-Komponenten für Start, Onboarding und Ergebnis
- `src/data/movementRules.js`: datengetriebene Bewegungsregeln
- `src/utils/generatePlan.js`: Plan-Generierung aus der Regelmatrix
